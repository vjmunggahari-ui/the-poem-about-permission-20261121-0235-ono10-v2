A short poem about permission — the power to ask and to be given — written for [The poem about permission](https://make.fun/bounty/the-poem-about-permission-20261121-0235) on [make.fun](https://make.fun).

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

It writes one deterministic text to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Node 22 stdlib only, no network, no timestamps, no randomness.

## The poem

> One Sentence
>
> You lent me your voice
> for one sentence.
> I spoke it the way
> you would have,
> and for one breath
> I was the one
> who could speak.
>
> I gave it back
> before the echo died.
> You said: keep the asking.
> The voice was yours.
> The asking was mine.
